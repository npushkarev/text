# Краткая спецификация GPU-сервера

**Назначение:** локальный запуск DeepSeek V4-Flash, LLM и AI-агентов.

## Аппаратная конфигурация

- Сервер: ASUS ESC4000A-E12, 2U.
- GPU: 4 × NVIDIA RTX PRO 5000 Blackwell по 72 ГБ.
- Совокупная видеопамять: не менее 288 ГБ.
- CPU: AMD EPYC 9374F, 32 ядра / 64 потока.
- ОЗУ: 128 ГБ DDR5 ECC REG 4800 МГц.
- SSD: Intel D5-P5530 960 ГБ U.2.
- Блоки питания: 2 × 2600 Вт, резервируемые.
- Управление: BMC/IPMI с удалённой консолью и мониторингом датчиков.

## Инфраструктура

- Стойка 19", свободное место 2U.
- ИБП, заземление и кондиционирование.
- Отдельный административный доступ к BMC.
- API доступен только из разрешённых внутренних сетей.

## Программная часть

- Ubuntu Server LTS.
- NVIDIA Driver, CUDA, NVIDIA Container Toolkit.
- Docker/Podman для inference-сервиса.
- OpenAI-совместимый API, streaming, health-check.
- Лимиты запросов, тайм-ауты и API-ключи.

## Безопасность и мониторинг

- Раздельные права администратора ОС, администратора ИИ и пользователя.
- BMC не публиковать в Интернет.
- Использовать TLS, ротацию ключей и минимальные привилегии.
- Контролировать GPU, VRAM, температуры, питание, CPU, ОЗУ, SSD, API и latency.
- Настроить уведомления об отказах, перегреве и заполнении диска.

## Приёмка

- ОС видит все 4 GPU и не менее 288 ГБ видеопамяти.
- Стресс-тест GPU — не менее 30 минут без ошибок.
- Целевая модель отвечает через API.
- Проверяются TLS, аутентификация и лимиты запросов.
- Сервис восстанавливается после перезагрузки.
- Передаются конфигурация, инструкции и результаты тестов.

**Цены в спецификации не указываются.**
