Что даёт настройка кеша — коротко
  
  Без cache (каждая сборка с нуля)

  - Grpc-дерево: 15-25 минут
  - Каждый билд тянет источники → распаковывает → компилирует
  - Disk thrash на каждом запуске

  С локальным cache (Docker volume / CONAN_HOME)

  - Первая сборка: 15-25 минут
  - Повторная той же конфигурации: 30 секунд (Conan видит pre-built, пропускает)
  - Повторная с изменённым флагом: пересобирает только то что упёрлось, остальное hit
  - Выигрыш: ×30 на повторных билдах одного агента

  С ProGet Conan-feed (общий cache на все агенты)

  - Один агент собрал → запушил на ProGet
  - Все остальные агенты скачивают готовые бинари (~2-3 минуты вместо сборки)
  - Новый агент не нужно warming-up'ить
  - Выигрыш: ×8-10 на свежем агенте + полная независимость от того кто что собрал

  С pre-baked Docker image

  - Pre-bake раз в неделю/месяц: всё внутри образа
  - TC билд: docker pull (минута) + downstream-сборка (1-3 мин)
  - Без pre-bake: pull base + Conan-setup + dep-fetch + downstream (10-15 мин)
  - Выигрыш: ×5 на каждый downstream билд
